# 미국 종목 심볼 목록

- 출처: https://github.com/rreichel3/US-Stock-Symbols (커밋 0925ee2, 2026-11-26 가져옴)
- 원본은 NASDAQ·NYSE·AMEX 거래소별 목록이며 매일 자정(미국 동부시간) 갱신됩니다.
- `*_tickers.txt/json`: 티커만, `*_full_tickers.json`: 회사명·시가총액·섹터 등 상세
- `us_tickers_merged.txt`: 세 거래소 티커를 합쳐 중복 제거한 목록 (직접 생성)
- 원본 저장소에는 LICENSE 파일이 없어 출처를 명시합니다. 이 폴더의 파일은 시점 기준 복사본입니다.
- 참고: ETF(예: QQQ)는 이 목록에 포함되지 않습니다.
